# Установка и настройка

Подробная инструкция: запуск, база данных, хостинг, сайт, админ-панель и акции.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN и ADMIN_IDS
python -m bot.main
```

- Токен выдаёт [@BotFather](https://t.me/BotFather).
- Свой Telegram ID можно узнать командой `/id` в самом боте, затем вписать в `ADMIN_IDS` и перезапустить.
- Меню напитков меняется переменной `DRINKS` в `.env`.

## База данных

Два варианта, выбираются переменными окружения:

- **Локально — Excel-файл** (`DB_PATH`, по умолчанию `data/coffee.xlsx`). Создаётся сам. Не редактируйте его, пока бот работает: бот держит базу в памяти и перезапишет правки.
- **На хостинге — облачный Postgres** (`DATABASE_URL`), например бесплатный [Neon](https://neon.tech). Таблицы создаются сами, новые колонки добавляются при обновлении.

В обоих случаях кнопка «Excel-база» присылает админу файл с листами:

| Лист | Что внутри |
|---|---|
| Пользователи | ID, логин, хеш пароля, Telegram ID, код карты, дата регистрации, всего кофе, любимый напиток |
| Покупки | журнал: дата, гость, напиток |
| Напитки | общий рейтинг напитков |
| Акции | история рассылок |

Любимый напиток считается по журналу покупок.

## Бесплатный хостинг: Render + Neon

1. На [neon.tech](https://neon.tech) создайте проект и скопируйте строку подключения (`postgresql://...`).
2. На Render: **New → Web Service**, этот репозиторий, тариф **Free**.
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python -m bot.main`
   - Environment: `BOT_TOKEN`, `ADMIN_IDS`, `DATABASE_URL`
3. После деплоя бот сам зарегистрирует вебхук (адрес берётся из `RENDER_EXTERNAL_URL`).

Бесплатная служба Render засыпает после 15 минут без обращений. Сообщение боту её будит, но первый ответ после простоя приходит с задержкой около минуты. То же касается виджета «Карта гостя» на сайте: он обращается к этой же службе, поэтому первая регистрация или вход после простоя могут занять до минуты.

## Сайт

Статическая страница без сборки — откройте `site/index.html` или выложите папку `site/` на любой хостинг (GitHub Pages, Netlify и т.п.).

Быстрый запуск на Render (бесплатно): откройте
https://render.com/deploy?repo=https://github.com/kassse1/Astana-Coffee-Express,
войдите через GitHub и нажмите Apply — настройки берутся из `render.yaml`.


Перед публикацией поменяйте в `site/index.html`:
- блок `SITE` внизу файла — ссылка на бота (`bot`) и адрес службы бота (`api`, нужен для виджета карты на сайте); контакты — в секции «Контакты»;
- список напитков в секции «Напитки», если в аппаратах другой набор;
- «каждая 6-я чашка» (три места на странице) — если меняете `FREE_EVERY` в боте.
- выбранный на сайте фон карты сохраняется в базе, и бот присылает карту с тем же фоном (адрес службы бота прописан в `site/index.html` как `SITE.api` и в `site/design.html` как `API`);
- фоны карты гостя в папке `site/cards/` (`card-1.webp` … `card-6.webp`, ширина 960, и миниатюры `card-1-s.webp` … шириной 320) — замените файлы своими, формат WebP, пропорции 16:9.

## Админ-панель

Закрытая страница `site/admin.html`. Пароля нет: админ (его Telegram ID есть в `ADMIN_IDS`) отправляет боту команду `/admin`
и получает личную ссылку, она действует 12 часов. Для ссылки в настройках бота должен быть задан `SITE_ORIGIN` — адрес сайта.

В панели:

- выручка за день, 7 и 30 дней, график по дням, популярные напитки, выручка по аппаратам;
- число гостей, статистика программы лояльности, самые активные гости;
- аппараты: добавить, изменить, выключить (активные видны на сайте в «Где найти» и в боте при отметке кофе);
- обращения с сайта: заявки на установку, жалобы, возвраты — с заметкой и статусом; о новом обращении бот сразу пишет админам;
- цена за чашку и строка акции на сайте, рассылка акции всем гостям в Telegram.

Важно: продажи считаются по чашкам, отмеченным в боте по карте гостя («Отметить кофе»). Покупки без карты панель не видит.
Чтобы выручка делилась по аппаратам, при отметке выберите аппарат — бот спросит сам, когда в панели есть хотя бы один.

Данные панели лежат в той же базе `DATABASE_URL` (таблицы `machines`, `sales`, `requests`, `settings`). Адрес службы бота
прописан в `site/admin.html` в константе `API`.

## Чашка за подписку на канал

В боте у вошедшего гостя есть кнопка «🎁 Кофе за подписку». Бот проверяет, подписан ли гость на канал, и даёт одну
бесплатную чашку (один раз на гостя). Когда админ отмечает кофе по штрихкоду, бот сам предупреждает о бонусе и
отмечает чашку бесплатной. Подписка не обязательна: без неё бот работает как обычно.

- Канал задаётся переменной `CHANNEL` (по умолчанию `@astanaCoffeeExpress`); пустое значение выключает акцию.
- **Бот должен быть администратором канала** — иначе Telegram не даёт проверить подписку.
